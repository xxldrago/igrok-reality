## 1. Система ролей

### Иерархия

```
master > leader > specialist > curator > player
```

### Определение ролей

| Роль | Описание | Назначается |
|------|----------|-------------|
| `player` | Участник квеста (по умолчанию) | Автоматически при регистрации |
| `curator` | Куратор — видит свою команду | Назначается мастером |
| `specialist` | Специалист | Назначается мастером |
| `leader` | Лидер — доступ к финансам, модерации | Назначается мастером |
| `master` | Мастер — полный доступ ко всему | Назначается вручную |

### Назначение ролей

- **Только master** может менять роли через API `POST /api/admin/users/{id}/role`
- Каждая смена роли записывается в таблицу `RoleHistory` с указанием того, кто назначил

## 2. Player (Игрок)

### Роль по умолчанию

Все новые пользователи получают роль `player` при регистрации.

### Доступные команды бота

| Команда | Описание | Ограничения |
|---------|----------|-------------|
| `/start` | Регистрация / приветствие | — |
| `/help` | Список команд | — |
| `/progress` | Прогресс: XP, streak, текущий день | — |
| `/profile` | Профиль: архетип, статистика, достижения | — |
| `/leaderboard` | Таблица лидеров | — |
| `/pay` | Оплата доступа к каналу | 4900₽ |
| `/referral` | Реферальная ссылка | — |
| `/clan` | Информация о клане | — |
| `/clan join <id>` | Вступить в клан | Должен быть без клана |
| `/clan leave` | Покинуть клан | — |
| `/today` | Показать доступные свитки на сегодня | — |
| `/wakeup` | Выполнить «Свиток Рассвета» (+5 XP) | 1 раз/день |
| `/cold` | Выполнить «Свиток Огня» (+5 XP) | 1 раз/день |
| `/scan` | Медитация — получить текст (+0 XP) | Только в медитативные дни |
| `/scanreport` | Медитация — отчёт с фото/видео (+5 XP) | Только в медитативные дни |
| `/breath` | Дыхательная практика (+5 XP) | 1 раз/день |
| `/micro` | Микро-привычка (+3 XP) | 1 раз/день |
| `/focus` | Теория дня (+3 XP) | 1 раз/день |
| `/food` | Питание (+3 XP) | 1 раз/день |
| `/sleep` | Ночной ритуал (+5 XP) | 1 раз/день |
| `/report` | Дневной отчёт (+2 XP, с фото/видео) | 1 раз/день |
| `/skip` | Пропустить сегодняшний день | — |

### Недоступные команды

- `/admin` — нет доступа к админ-панели
- `/myteam` — нет доступа к просмотру команды
- `/clan create` — только лидеры могут создавать кланы

### Участие в квесте

1. **Регистрация** → quiz на определение архетипа → получение роли `player`
2. **Ежедневно** → бот присылает свитки по расписанию (5:00, 8:00, 12:00, 16:00, 21:00 по времени сервера)
3. **Выполнение** → игрок отмечает команды, получает XP
4. **Прогресс** → streak (серия дней), XP, позиция в рейтинге
5. **Оплата** → после оплаты получает доступ к каналу с контентом

## 3. Curator (Куратор)

### Назначение

Назначается мастером. Видит участников, которых пригласил (свою «команду»).

### Доступные команды бота

Все команды игрока, плюс:

| Команда | Описание |
|---------|----------|
| `/myteam` | Просмотр своей команды (приглашённые игроки) |
| `/admin` | Вход в админ-панель (веб или TMA) |

### Доступ к админ-панели

| Раздел | Веб | TMA |
|--------|-----|-----|
| Дашборд | Ограниченный | Ограниченный |
| Пользователи | Просмотр | Просмотр |
| Свитки | Просмотр | Просмотр |
| Платежи | Ограниченный | Ограниченный |
| Финансы | Нет | Нет |
| Модерация | Нет | Нет |
| Рассылка | Нет | Нет |
| Настройки | Только чтение | Нет |
| Аудит | Нет | Нет |

### API доступ

| Эндпоинт | Метод | Доступ |
|-----------|-------|--------|
| `/api/admin/users` | GET | Да (список пользователей) |
| `/api/admin/users/{id}` | GET | Да (детали пользователя) |
| `/api/admin/settings` | GET | Да (только чтение) |

### Ограничения

- Не может создавать кланы
- Не может менять роли
- Не может отправлять рассылки
- Не может модерировать жалобы
- Не может создавать/распределять призовой фонд

## 5. Master (Мастер)

### Назначение

Полный доступ ко всем функциям платформы. Единственная роль, которая может назначать других администраторов.

### Доступные команды бота

Все команды, включая:

| Команда | Описание |
|---------|----------|
| `/admin` | Админ-панель |
| `/admin settings` | Настройки (из бота) |
| `/admin audit` | Аудит (из бота) |
| `/myteam` | Просмотр команды |

### Доступ к админ-панели

| Раздел | Веб | TMA |
|--------|-----|-----|
| Дашборд | Полный | Полный |
| Пользователи | Полный + назначение ролей | Полный |
| Свитки | Полный (CRUD) | Полный |
| Платежи | Полный + экспорт CSV | Полный |
| Финансы | Полный (создание/распределение фонда) | Полный |
| Модерация | Полный (разрешение жалоб) | Полный |
| Рассылка | Полный (все архетипы или фильтр) | Полный |
| Настройки | Полный (все настройки платформы) | Полный |
| Аудит | Полный | Полный |

### Эксклюзивные возможности (только master)

| Функция | Эндпоинт |
|---------|----------|

## 6. Механика квеста

### Длительность

- **90 дней** — полный цикл квеста
- День рассчитывается как `(сегодня - дата_начала).days + 1`
- Ограничен до 90 (если игрок пропускал дни)

### Типы дней

| Тип | Дни | Доступные команды | Макс. XP |
|-----|-----|-------------------|----------|
| **Стандартный** | Все остальные | wakeup, cold, breath, micro, focus, food, sleep, report | ~31 |
| **Медитативный** | 1, 8, 15, 22, 29, 36, 43, 50, 57, 64, 71, 78, 85 | Все стандартные + scan, scanreport | ~36 |
| **Дыхательный** | 7, 14, 21, 28, 35, 42, 49, 56, 63, 70, 77, 84 | Ограниченный набор | ~20 |
| **Осознанный** | 6, 13, 20, 27, 34, 41, 48, 55, 62, 69, 76, 83 | Только focus + report | ~8 |

### Расписание доставки свитков

| Время | Свиток | Команда | XP |
|-------------|--------|---------|-----|
| 05:00 | Рассвет | `/wakeup` | настраиваемый |
| 05:00 | Огонь | `/cold` | настраиваемый |
| 05:00 | Корни (медитация) | `/scan` → `/scanreport` | 0 → настраиваемый |
| 08:00 | Ветер | `/breath` | настраиваемый |
| 12:00 | Следы | `/micro` | настраиваемый |
| 16:00 | Зря | `/focus` | настраиваемый |
| 16:00 | Питание | `/food` | настраиваемый |
| 21:00 | Интеграция Истока | `/sleep` | настраиваемый |
|любое время| Отчёт | `/report` | 2 |

### Правила выполнения

1. **Одна команда = 1 раз в день** — уникальное ограничение `(user_id, quest_day, command)`
2. **Грейс-период** — 00:00–05:00 по местному времени считается за предыдущий день (для ночных смен)
3. **Антидубликат** — повторная попытка выполнить ту же команду отклоняется
4. **Отчёт** — `/report` и `/scanreport` принимают фото/видео через FSM (состояния `ReportState`)

### XP система

- **Начисление** — при выполнении команды через `progress_service.add_xp()`
- **Веса** — настраиваются через настройки платформы:
  - `xp_weight_common`: 10 (по умолчанию)
  - `xp_weight_individual`: 10
  - `xp_weight_ritual`: 5
  - `xp_weight_habits`: 5
- **Бонусы за streak:**
  - 7 дней: +50 XP
  - 30 дней: +250 XP
  - 90 дней: +1000 XP
- **Лидерборд** — Redis sorted set `leaderboard:xp`

### Streak (серия дней)

- Первое выполнение → streak = 1
- Следующий день → streak += 1
- Пропуск 2+ дней → streak сбрасывается до 1
- **Учёт по часовому поясу** пользователя, не сервера

## 7. Система оплаты

### Стоимость

- **4900 рублей** (490000 копеек)
- Валюта: RUB

### Процесс оплаты

1. Игрок отправляет `/pay`
2. Создаётся платёж (статус `pending`)
3. Если уже есть `pending` платёж — используется он (идемпотентность)
4. Вызывается API Platega.io для создания платёжной ссылки
5. Ссылка отправляется игроку
6. Игрок оплачивает на странице Platega

### Обработка вебхука

- Platega отправляет вебхук на `/webhook/platega`
- Проверяются заголовки `X-MerchantId` и `X-Secret`
- Статусы: `CONFIRMED` → `succeeded`, `CANCELED` → `canceled`, `CHARGEBACKED` → `chargebacked`, `REFUNDED` → `refunded`

### После успешной оплаты

1. Игрок получает **одноразовую ссылку** на канал `QUEST_CHANNEL_ID`
2. В `users.access_granted_at` записывается время
3. Если есть реферер — начисляется **комиссия 10%**

### При возврате/чарджбеке

- Доступ к каналу **отзывается** (бан + разбан в канале)

## 8. Реферальная система

### Как работает

1. При регистрации каждый игрок получает **уникальный реферальный код**
2. Ссылка: `https://t.me/{BOT_USERNAME}?start={referral_code}`
3. Новый игрок переходит по ссылке → привязывается к рефереру

### Команда

- `/referral` — показывает реферальную ссылку с кнопкой «копировать»

### Вознаграждение

- **10%** от первой оплаты приглашённого (разово)
- Комиссия начисляется на `CommissionBalance` реферера
- Реферер может вывести деньги через мастера (`POST /api/admin/payout`)

### Ограничения

- Один игрок может быть приглашён только одним реферером (уникальное ограничение `referee_id`)

## 9. Кланы

### Создание клана

- **Только лидеры и выше** могут создавать кланы
- Команда: `/clan create <название>`
- Владелец клана автоматически становится участником

### Вступление в клан

- `/clan join <clan_id>` — любой игрок, если ещё не в клане
- Один игрок может быть только в одном клане

### Покидание клана

- `/clan leave` — удаляет из клана
- Если клан остаётся пустым — **удаляется автоматически**

### Просмотр клана

- `/clan` — показывает:
  - Название и ID клана
  - Владелец
  - Количество участников
  - Общий XP клана
  - Средний XP и streak
  - Список участников с их статистикой

## 10. Уведомления и рассылки

### Типы уведомлений

| Тип | Описание | Когда |
|-----|----------|-------|
| `scroll_reminder` | Напоминание о невыполненных свитках | По расписанию (по умолч. 20:00 по времени сервера) |
| `streak_warning` | Предупреждение о потере streak | 23:00 по времени сервера ежедневно |
| `system` | Системные уведомления | По триггеру |
| `broadcast` | Рассылка от администратора | По запросу master/leader |

### Автоматические уведомления

1. **Доставка свитков** — 5 раз в день (5:00, 8:00, 12:00, 16:00, 21:00 по времени сервера)
2. **Вечернее напоминание** — настраиваемое время (по умолч. 20:00 по времени сервера)
3. **Предупреждение о streak** — 23:00 по времени сервера для игроков, которые ещё не выполнили сегодня

### Рассылки (broadcast)

- **Master** может отправлять рассылки всем или по архетипу
- Сообщения попадают в таблицу `notifications`
- Worker `send_pending_notifications` отправляет их раз в минуту через Bot API

### Master Feed

Отчёты игроков (фото/видео/текст) из команд `/report` и `/scanreport` автоматически пересылаются в чат мастера с информацией:
- Имя пользователя
- Архетип
- День квеста
- Текст отчёта
- Медиа (фото/видео)

## 11. Админ-панель

### Два интерфейса

1. **Веб-админка** (`src/admin/`) — полноценная админ-панель на React
2. **TMA** (`src/tma/`) — Telegram Mini App для управления из бота

### Авторизация

- **Веб:** логин/пароль → JWT токен (24 часа)
- **TMA:** Telegram initData → проверка подписи → JWT токен

### Разделы

| Раздел | Описание | Curator | Leader | Master |
|--------|----------|---------|--------|--------|
| **Дашборд** | KPI: пользователи, платежи, streak, конверсия | Ограниченно | Полный | Полный |
| **Пользователи** | Список, поиск, детали, прогресс | Просмотр | Полный | Полный + роли |
| **Свитки** | Управление свитками по дням | Просмотр | CRUD | CRUD |
| **Платежи** | Список платежей, статусы, детали | Ограниченно | Полный | Полный + экспорт |
| **Финансы** | Комиссии, призовой фонд | Нет | Просмотр | Полный |
| **Модерация** | Жалобы на контент | Нет | Просмотр | Разрешение |
| **Рассылка** | Отправка сообщений игрокам | Нет | Да | Да |
| **Настройки** | Конфигурация платформы | Чтение | Нет | Полный |
| **Аудит** | Журнал действий администраторов | Нет | Да | Да |

### Настройки платформы (master)

| Ключ | Описание | Тип |
|------|----------|-----|
| `scroll_publish_hour` | Час публикации свитков | int |
| `scroll_publish_minute` | Минута публикации | int |
| `xp_weight_common` | Вес XP за общие задания | int |
| `xp_weight_individual` | Вес XP за индивидуальные задания | int |
| `xp_weight_ritual` | Вес XP за ритуалы | int |
| `xp_weight_habits` | Вес XP за привычки | int |
| `streak_bonus_7d` | Бонус за 7 дней streak | int |
| `streak_bonus_30d` | Бонус за 30 дней streak | int |
| `streak_bonus_90d` | Бонус за 90 дней streak | int |
| `prize_fund_percent` | Процент от платежей в призовой фонд | int |
| `welcome_message` | Приветственное сообщение | str |
| `quiz_intro` | Текст вступления квиза | str |
| `quiz_questions` | JSON с вопросами квиза | JSON |
| `quiz_results` | JSON с описаниями архетипов | JSON |
| `archetype_scores` | JSON с весами архетипов | JSON |

### Архетипы

При регистрации игрок проходит квиз и определяет свой архетип:

| Архетип | Описание |
|---------|----------|
| 🧠 **Голова** | Рациональный, аналитический |
| 🛡️ **Панцирь** | Надёжный, стабильный |
| 🌪️ **Вихрь** | Энергичный, динамичный |
| 👻 **Призрак** | Интуитивный, гибкий |

Архетип определяется набором ответов в квизе и влияет на:
- Индивидуальные задания в свитках
- Фильтрацию рассылок
- Отображение в профиле и leaderboard
