**Admin can manage scroll content and view payment transactions.**

<task type="tracer">

  <action>
    Expand `src/app/api/routes/admin.py` with scroll CRUD and payment management endpoints. Apply `Depends(get_current_user)` and role checks to all endpoints.

    **Scroll endpoints (require role: master, leader):**

    1. **GET /api/admin/scrolls** — List scrolls with pagination and filter:
       - Query params: `archetype: str | None = None`, `day_number: int | None = None`, `page: int = 1`, `page_size: int = 20`
       - Return `{ scrolls: [...], total: int, page: int, page_size: int }`
       - Scroll object: `{ id, day_number, archetype, text, media_file_id, created_at, updated_at }`
       - Order by `day_number ASC, archetype ASC`

    2. **GET /api/admin/scrolls/{scroll_id}** — Single scroll detail

    3. **POST /api/admin/scrolls** — Create scroll:
       - Request body: `{ day_number: int, archetype: str, text: str, media_file_id: str | None }`
       - Validate: `day_number` in 1-90, `archetype` in ["head", "shell", "whirlwind", "ghost"]
       - Validate: unique constraint (day_number + archetype) — catch IntegrityError
       - Create AuditLog: action="scroll_created", details=f"day={day_number} archetype={archetype}"
       - Return created scroll

    4. **PUT /api/admin/scrolls/{scroll_id}** — Update scroll:
       - Request body: `{ text: str, media_file_id: str | None }` (day_number and archetype immutable)
       - Update fields, return updated scroll
       - Create AuditLog: action="scroll_updated"

    5. **DELETE /api/admin/scrolls/{scroll_id}** — Delete scroll:
       - Delete from DB
       - Create AuditLog: action="scroll_deleted"
       - Return 204

    **Payment endpoints (require role: master, leader):**

    6. **GET /api/admin/payments** — List payments with pagination and filter:
       - Query params: `status: str | None = None`, `user_id: UUID | None = None`, `page: int = 1`, `page_size: int = 20`
       - Return `{ payments: [...], total: int, page: int, page_size: int }`
       - Payment object: `{ id, user_id, amount, currency, status, payment_method, platega_transaction_id, created_at }`
       - Join with User to include `user_name` (first_name + last_name) and `user_username`
       - Order by `created_at DESC`

    7. **GET /api/admin/payments/{payment_id}** — Payment detail with user info:
       - Return all payment fields plus user profile summary
       - Return 404 if not found

    **Pydantic models:**
    - `ScrollCreateRequest(BaseModel)`: day_number (1-90), archetype (Literal), text (str), media_file_id (str | None)
    - `ScrollUpdateRequest(BaseModel)`: text (str), media_file_id (str | None)
    - `ScrollResponse(BaseModel)`: id, day_number, archetype, text, media_file_id, created_at, updated_at
    - `PaymentResponse(BaseModel)`: id, user_id, user_name, user_username, amount, currency, status, payment_method, platega_transaction_id, created_at

    Use `async with get_session() as session:` for DB access, consistent with existing admin.py pattern.
