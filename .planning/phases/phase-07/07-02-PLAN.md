    1. **GET /api/admin/users** — List users with search, filter, pagination:
       - Query params: `search: str = ""` (searches first_name, last_name, username, telegram_id), `archetype: str | None = None`, `is_active: bool | None = None`, `has_paid: bool | None = None`, `page: int = 1`, `page_size: int = 20`
       - Query User model with filters applied as SQLAlchemy WHERE clauses
       - `search` uses `ilike` for case-insensitive partial match on first_name, last_name, username; exact match on telegram_id (try int conversion first)
       - Return `{ users: [...], total: int, page: int, page_size: int }`
       - Each user object: `{ id, telegram_id, first_name, last_name, username, archetype, xp, streak, is_active, paid_at, started_at, created_at }`
       - Order by `created_at DESC`

    2. **GET /api/admin/users/{user_id}** — Full user detail:
       - Return all user fields plus computed data:
         - `completions_count`: count of UserCompletion records
         - `payments`: list of Payment records (id, amount, status, created_at)
         - `referrals_count`: count of Referral records where user is referrer
         - `commission_balance`: CommissionBalance fields if exists
       - Join related tables in single query using `selectinload` or separate queries
       - Return 404 if user not found

    3. Add audit log creation for user views (optional, low priority — create AuditLog with action="user_viewed" when user detail is accessed)

    **Pydantic response models:**
    - `UserListItem(BaseModel)`: id, telegram_id, first_name, last_name, username, archetype, xp, streak, is_active, paid_at, started_at, created_at
    - `UserListResponse(BaseModel)`: users: list[UserListItem], total, page, page_size
    - `UserDetailResponse(BaseModel)`: extends UserListItem with payments, completions_count, referrals_count, commission_balance

    **Import additions:**
    - `from sqlalchemy import select, func, or_`
    - `from sqlalchemy.orm import selectinload`
    - `from app.shared.models.user import User, Referral`

    - `from app.shared.models.commission import CommissionBalance`
    - `from app.shared.database import get_session`
