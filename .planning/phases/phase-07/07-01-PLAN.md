# Plan 07-01: React App Scaffolding, JWT Auth, Routing

**Create React + Ant Design admin app with JWT authentication and protected routing.**

## Tasks

  <name>Task 1: React scaffolding + backend JWT auth endpoint</name>
  <files>

  </files>
  <action>
    **Backend (FastAPI):**

    1. Create `src/app/api/auth.py` with:
       - `LoginRequest(BaseModel): username: str, password: str`
       - `TokenResponse(BaseModel): access_token: str, token_type: str = "bearer"`
       - `create_access_token(data: dict) -> str` — encode with `jwt.encode` using `settings.JWT_SECRET` (add to config.py) and HS256, expiry 24h
       - `decode_access_token(token: str) -> dict` — decode and return payload
       - `POST /api/admin/auth/login` — validate credentials against hardcoded admin users (for v1: single master account, username/password from env vars `ADMIN_USERNAME`/`ADMIN_PASSWORD`), return JWT
       - `GET /api/admin/auth/me` — return current user info from JWT

    2. Create `src/app/api/dependencies.py` with:
       - `get_current_user(token: str = Depends(oauth2_scheme)) -> dict` — decode JWT, raise 401 if invalid
       - `require_role(*roles: str)` — dependency factory that checks `role` claim in JWT, raises 403 if not in allowed roles

    3. Update `src/app/api/main.py`:
       - Add `from fastapi.staticfiles import StaticFiles`
       - Add `from fastapi.responses import FileResponse`
       - Add `from app.api.auth import auth_router`
       - Include `auth_router`
       - After all routes, mount static files: `app.mount("/admin", StaticFiles(directory="src/admin/dist", html=True), name="admin")`
       - Add catch-all route serving `src/admin/dist/index.html` for SPA routing

    4. Update `src/app/shared/config.py`:
       - Add `JWT_SECRET: str = "change-me-in-production"`
       - Add `ADMIN_USERNAME: str = "admin"`
       - Add `ADMIN_PASSWORD: str = "admin"`

    5. Add `pyjwt` to `pyproject.toml` dependencies

    **Frontend (React):**

    6. Initialize `src/admin/` with Vite React TypeScript template via `npm create vite@latest`
    7. Install dependencies: `antd`, `@ant-design/icons`, `react-router-dom`, `axios`
    8. Create `src/admin/src/contexts/AuthContext.tsx`:
       - Store JWT in localStorage
       - Provide `login(username, password)`, `logout()`, `isAuthenticated`, `user` values
       - On mount, check localStorage for existing token, validate with `GET /api/admin/auth/me`

    9. Create `src/admin/src/services/api.ts`:
       - Axios instance with `baseURL = "/api"` and interceptor that adds `Authorization: Bearer {token}` from localStorage

    10. Create `src/admin/src/pages/Login.tsx`:
        - Ant Design Form with username/password fields
        - Calls `authContext.login()`, redirects to `/` on success
        - Shows error message on failure

    11. Create `src/admin/src/layouts/AdminLayout.tsx`:
        - Ant Design Layout with Sider (navigation) + Content
        - Sidebar menu: Пользователи, Свитки, Платежи, Настройки, Аудит
        - Uses `react-router-dom` Outlet

    12. Create `src/admin/src/App.tsx`:
        - React Router with routes: `/login` (Login page), `/` (AdminLayout with nested routes)
        - ProtectedRoute component that checks `isAuthenticated`, redirects to `/login` if not
        - Placeholder routes for /users, /scrolls, /payments, /settings, /audit (implemented in later plans)

    13. Create `src/admin/src/main.tsx`:
        - Render App wrapped in AuthProvider

    14. Configure `src/admin/vite.config.ts`:
        - Proxy `/api` to `http://localhost:8000` for development
        - Output to `dist/` for production

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→API | Admin login credentials cross untrusted boundary |
| API→DB | Admin queries read sensitive user data |
| JWT→API | Token carries role claim — must be validated on every request |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Spoofing | /api/admin/auth/login | high | mitigate | Rate limit login endpoint (5/min per IP). Hardcoded credentials for v1, env vars. |
| T-07-02 | Tampering | JWT token | high | mitigate | HS256 with secret from env. 24h expiry. No sensitive data in payload (only user_id, role). |
| T-07-03 | Info Disclosure | /api/admin/auth/me | medium | mitigate | Only return username and role, never password hash. |
| T-07-04 | Elevation | Role check | high | mitigate | require_role dependency enforced on all admin endpoints. |
| T-07-05 | DoS | /api/admin/auth/login | low | accept | Rate limiting deferred to Phase 8 (nginx/caddy layer). v1 uses env-only credentials. |
</threat_model>
