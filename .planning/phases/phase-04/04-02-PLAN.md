  <behavior>
    - First completion ever (streak_last_date is None): streak becomes 1
    - Completing on same day as last completion: streak unchanged
    - Completing the day after last completion: streak increments by 1
    - Missing a day (2+ days gap): streak resets to 1
    - Day boundary is calculated in user's timezone, not UTC
  </behavior>
  <action>
Add `update_streak(user_id: UUID) -> int` to `src/app/bot/services/progress_service.py`:

1. Import `from zoneinfo import ZoneInfo` and `from datetime import date, datetime`
2. Load User by id using existing session_factory pattern
3. Get user's timezone: `tz = ZoneInfo(user.timezone)` (default "Europe/Moscow" from model)
4. Calculate today in user's timezone: `today = datetime.now(tz).date()`
5. Apply streak logic:
   - If `user.streak_last_date is None`: set streak=1
   - Elif `user.streak_last_date == today`: no change (already completed today)
   - Elif `user.streak_last_date == today - timedelta(days=1)`: streak += 1 (consecutive)
   - Else: streak = 1 (broken streak, reset)
6. Set `user.streak_last_date = today`
7. Commit and return user.streak

Wire into `handle_scroll_completion` in scroll.py: after `add_xp` call, call `await update_streak(user_id)`.

Key constraint: Use `from zoneinfo import ZoneInfo` (stdlib, Python 3.9+). Do NOT use pytz. The user.timezone field stores IANA timezone strings like "Europe/Moscow", "Asia/Almaty".
