Create the following:

1. Add to `src/app/bot/services/commission.py`:
   - `async def process_payout(user_id: UUID, amount: int, admin_id: UUID | None = None) -> dict`:
     a. Open session, query CommissionBalance by user_id
     b. If balance not found, return {"success": False, "error": "No commission balance found"}
     c. If balance.total_pending < amount, return {"success": False, "error": "Insufficient balance", "pending": balance.total_pending}
     d. In same session: balance.total_pending -= amount, balance.total_paid_out += amount
     e. Create AuditLog entry: admin_id=admin_id, action="commission_payout", details=f"user_id={user_id}, amount={amount}"
     f. Commit both balance update and audit log atomically
     g. Return {"success": True, "amount": amount, "new_pending": balance.total_pending, "new_paid_out": balance.total_paid_out}
   - `async def get_commission_balance(user_id: UUID) -> dict | None`:
     a. Query CommissionBalance by user_id
     b. If found return {"total_earned": b.total_earned, "total_pending": b.total_pending, "total_paid_out": b.total_paid_out, "last_commission_at": b.last_commission_at}
     c. If not found return None
   - Import AuditLog from app.shared.models.audit

2. `src/app/api/routes/admin.py` — Admin API router:
   - `admin_router = APIRouter(prefix="/api/admin", tags=["admin"])`
   - `@admin_router.post("/payout")` endpoint:
     a. Request body: Pydantic model `PayoutRequest(user_id: UUID, amount: int)` with Field(ge=1) for amount
     b. Call process_payout(user_id, amount)
     c. Return JSON response with success status and balance info
     d. On failure, return 400 with error message
   - `@admin_router.get("/commission/{user_id}")` endpoint:
     a. Call get_commission_balance(user_id)
     b. Return JSON with balance data or 404 if not found
   - Import: APIRouter, Request from fastapi, UUID, Pydantic BaseModel, process_payout, get_commission_balance
   - Follow patterns from existing API routes (webhooks.py uses APIRouter)
