# Игрок.Реальность

## What This Is

Telegram-платформа для проведения 90-дневного геймифицированного квеста. Игроки получают ежедневные задания («Свитки»), проходят тест на архетип, выполняют задания, начисляют XP и стрики. Мастер управляет контентом, пользователями и экономикой через веб-админку. Система полностью автоматизирует типовые операции: допуск, рассылка, контроль оплаты, учёт прогресса, начисление вознаграждений.

## Core Value

Автоматическая ежедневная доставка персонализированных Свитков 500+ игрокам без потерь и ручного участия Мастера.

### Out of Scope

- Микросервисы — избыточны для бюджета и нагрузки
- Мобильное приложение — Telegram-first
- Онлайн-чат между игроками — не в ТЗ
- Видео-контент в Свитках — хранение/передача дорогая
- Мультиязычность — только русский
- Автоматические выплаты наставникам — ручная фиксация через админку

## Context

- Стек: Python 3.11+, aiogram 3.x, FastAPI, PostgreSQL 15+, Redis, React + Vite, Docker Compose
- Нагрузка: до 500 активных игроков в потоке, пик — утренняя рассылка в 08:00
- Telegram Bot API лимит: ~20-25 сообщений/сек в личный чат
- Архитектура: модульный монолит (бот, API, воркер, планировщик — отдельные процессы)
- Деплой: Docker Compose на российских VPS (152-ФЗ)
- Платежи: Platega.io (СБП, карточный эквайринг, крипто)

## Key Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Модульный монолит вместо микросервисов | Бюджет, сроки, умеренная нагрузка | — Pending |
| Redis + ARQ вместо Celery | Легче, проще, достаточно для задач | — Pending |
| APScheduler для триггеров + ARQ для исполнения | Чёткое разделение ответственности | — Pending |
| PostgreSQL 15+ (async через SQLAlchemy 2.0) | Зрелость, JSONB для гибких схем | — Pending |
| React + Vite для админки | Скорость разработки, TypeScript | — Pending |
| Хранение streak по TZ потока (не сервера) | Корректный сброс в полночи по местному времени | — Pending |
| Транзакционность: оплата → доступ → комиссия | Атомарность, нет потерь | — Pending |
| Медиа: file_id + дубль в S3 | Защита от потери при удалении Telegram | — Pending |
